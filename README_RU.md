# MiTV Apple Style Launcher — Full HD

Стартовый проект лаунчера для Xiaomi Mi TV Stick и телевизора DEXP. Интерфейс рассчитан на 16:9 и Full HD (1920×1080), с крупными зонами фокуса для пульта и умеренными анимациями.

## Что включено
- Тёмная тема и верхняя навигационная строка.
- Большой hero-баннер с градиентом.
- Демонстрационные карточки категорий/фильмов.
- Список приложений, которые объявляют Android TV / Leanback launcher activity.
- Плитки с фокусом пульта, масштабированием и запуском через OK.
- Обработка кнопки Back.
- Русские подписи и минималистичный интерфейс.

## Честно о постерах и иконках
Карточки фильмов сейчас декоративные: это градиентные обложки-заглушки, а не реальные постеры. Иконки приложений сейчас выполнены символами/первыми буквами. Это сделано без внешних сетевых запросов и не требует API-ключей. Следующим этапом можно подключить легальный каталог метаданных и изображения, а также получать реальные значки через Android PackageManager.

## Требования
- Android Studio (актуальная стабильная версия).
- Android SDK Platform 35.
- Интернет для первого скачивания Gradle-плагинов и SDK.
- JDK 17 (обычно входит в Android Studio).

## Сборка APK
1. Распакуйте архив.
2. В Android Studio нажмите **Open** и выберите папку `MiTV_AppleStyle_Launcher`.
3. Подтвердите Gradle Sync. При запросе установите Android SDK 35.
4. Откройте **Build → Build APK(s)**.
5. Debug APK обычно находится по пути:
   `app/build/outputs/apk/debug/app-debug.apk`

## Установка на Mi TV Stick
1. Скопируйте APK на приставку (например, через USB-флешку с подходящим OTG-адаптером, файловый менеджер или ADB).
2. В Android TV разрешите установку неизвестных приложений именно тому приложению, через которое открываете APK.
3. Установите APK и запустите **MiTV Apple Style** из списка приложений.

## Управление
- Стрелки — переход между фокусируемыми элементами.
- OK — открыть выбранное приложение.
- Назад — свернуть лаунчер в фон.

## Сделать домашним экраном
Проект объявляет `LEANBACK_LAUNCHER`, поэтому должен отображаться среди приложений Android TV. Но прошивка Xiaomi может не позволить выбрать стороннее приложение как системный Home или может сбросить выбор после обновления. Проверьте настройки приложений/домашнего экрана на своей версии прошивки.

## Ограничения текущего прототипа
- Реальные постеры, часы, погода, поиск и пользовательские настройки ещё не реализованы.
- Видимость сторонних приложений зависит от версии Android и ограничений пакетов.
- Это исходный проект, а не заранее собранный и проверенный APK. Сборка требует Android Studio; в этом окружении APK не компилировался и не тестировался на приставке.


## Сборка APK через GitHub Actions (без компьютера)

В проект добавлен workflow `.github/workflows/build-apk.yml`. После отправки файлов в GitHub он автоматически соберёт APK.

### Загрузка проекта с телефона Samsung
1. Установите Termux из официального каталога F-Droid: https://f-droid.org/packages/com.termux/ . Не используйте случайные APK-сайты.
2. Создайте на https://github.com/new новый **пустой** репозиторий, например `MiTV-AppleStyle-Launcher`. Не добавляйте README или лицензию на этапе создания.
3. Скачайте ZIP проекта на телефон и распакуйте его в приложении «Мои файлы» (папка проекта внутри называется `MiTV_AppleStyle_Launcher`).
4. В Termux выполните `termux-setup-storage`, разрешите доступ к файлам, затем установите Git: `pkg update && pkg install git` .
5. Перейдите в распакованную папку проекта. Путь зависит от того, куда вы распаковали ZIP; обычно это `/storage/emulated/0/Download/MiTV_AppleStyle_Launcher`. Команды:

```sh
cd /storage/emulated/0/Download/MiTV_AppleStyle_Launcher
git init
git add .
git commit -m "Initial launcher project"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

Замените `ВАШ_ЛОГИН` и `ИМЯ_РЕПОЗИТОРИЯ` на свои значения. Если Git попросит пароль, GitHub не принимает обычный пароль аккаунта: нужен Personal Access Token с доступом к репозиторию. Не отправляйте токен никому и не публикуйте его.

### Скачать собранный APK
1. Откройте репозиторий на GitHub → вкладка **Actions**.
2. Откройте последний запуск **Build Android TV Launcher APK** и дождитесь зелёного статуса.
3. Внизу запуска скачайте артефакт `MiTV-AppleStyle-debug-APK` (ZIP). Распакуйте его — внутри будет `app-debug.apk`.
4. Перенесите APK на Mi TV Stick, например через USB/облачное хранилище или приложение для передачи файлов, и установите его. Для установки может потребоваться разрешить установку неизвестных приложений.

Примечание: это debug APK для тестирования, не публикационная сборка. Workflow добавлен, но сам проект в облаке ещё не собирался и успешная компиляция пока не подтверждена.
